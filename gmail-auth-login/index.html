Login Tester
Google Identity Demo

Login Tester is a demonstration application that tests Google Sign-In and shows the basic profile information returned by Google after consent. It does not read, send, or modify Gmail messages.

Purpose: evaluate Google authentication and display the signed-in user's name, email, profile photo, verification state, and Google account subject ID.

Data use: profile data is displayed in this browser for the demonstration and is not sent to or stored by a Login Tester server.
